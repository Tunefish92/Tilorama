# Tilorama

**A fast deep-zoom viewer for gigapixel images.**

Drop in an image (or browse or paste it). The server cuts it into a tile pyramid, like Google Maps, and
caches the tiles. The browser then streams only the tiles that are currently visible, so a gigapixel image
opens and pans as smoothly as a photo. Tiling a 900 MP TIFF takes about 15 s.

- Formats: JPEG, PNG, WebP, TIFF, GIF, AVIF, SVG
- Zoom, rotate, flip, minimap, fullscreen, keyboard shortcuts, light and dark theme
- Tiles are generated by [libvips](https://www.libvips.org/) and rendered with [OpenSeadragon](https://openseadragon.github.io/)
- Tells you in the page when a newer version is out, and what changed after an update

## Quick start

```sh
docker run -d --name tilorama -p 127.0.0.1:8080:8080 -v tilorama-data:/data tunefish92/tilorama:latest
```

Open http://localhost:8080.

With Docker Compose, save this as `docker-compose.yml` and run `docker compose up -d`:

```yaml
services:
  tilorama:
    image: tunefish92/tilorama:latest
    restart: unless-stopped
    environment:
      # Owner of the data folder on the host; the app runs as this user.
      PUID: 1000
      PGID: 1000
    ports:
      - "127.0.0.1:8080:8080"
    volumes:
      # Uploaded originals, tiles and settings.
      - ./tilorama-data:/data
```

Tilorama has no login: everyone who can reach the port can open images and clear the cache. The examples
bind it to the machine it runs on. Publish the port as `8080:8080` only on a network you trust.

## Tags

- `latest`: the newest release
- `1.2.3`: a specific release

Images are built for `linux/amd64` and `linux/arm64`. The same image is on GitHub's registry as
`ghcr.io/tunefish92/tilorama`.

## Settings

| Variable | Default | Effect |
| --- | --- | --- |
| `PUID`, `PGID` | `1000` | The user the app runs as and that owns `/data` |
| `TileCache__Root` | `/data` | Data folder inside the container |

Tile size, format, quality and the cache size limit are set in the page (Settings, key `S`).
